================================================================================
  DOCUMENTATION DU PROJET ANVDKO (texte brut)
================================================================================

Ce document decrit l'organisation du depot, les zones applicatives (site
public, espace administration, espace membre), les principales bases de
donnees et tables observees dans le code, ainsi qu'un plan fonctionnel
general. Issu de l'analyse du code source au moment de sa redaction.

Encodage recommande : UTF-8


--------------------------------------------------------------------------------
1. VUE D'ENSEMBLE
--------------------------------------------------------------------------------

ANVDKO est une application web PHP orientee association, deployee typiquement
sous WAMP (Windows, Apache, MySQL, PHP). Elle couvre :

  - une vitrine et des formulaires publics (adhesion, contact) ;
  - un back-office (dossier anvdko/) pour les comptes "administration"
    (table utilisateurs) ;
  - un espace membre (dossier membres/) pour les personnes enregistrees dans
    la table membres.

Le theme administration repose sur des assets type Phoenix (Bootstrap, Feather
icons, etc.). L'espace membre et le site public utilisent Bootstrap et des
gabarits HTML dedies.

--------------------------------------------------------------------------------
4. MODELE DE DONNEES (TABLES REPEREES DANS LE CODE)
--------------------------------------------------------------------------------

Le schema SQL complet n'est pas versionne dans le depot (sauf script partiel
pour les depenses). Liste des noms de tables reellement utilises dans les
requetes PHP.

4.1 Association et utilisateurs
--------------------------------
  configurations     Identite de l'association (nom/sigle, contacts, logo).
                     Liee au contexte session "configuration".

  utilisateurs       Comptes administration (pseudo, telephone, email, mot de
                     passe, statut, role secretaire, id_configuration).

  membres            Adherents (identite, genre, cotisation, membre_bureau,
                     qr_url, num_adhesion, dates, statut, etc.).

4.2 Cotisations et paiements
-----------------------------
  paiements                        Paiements mensuels par membre et par mois
                                   (mois_payer, montants, statuts Paye, Moitie paye).

  config_cotisations_exceptionnelles   Motifs d'exception (montants standard,
                                       par genre, bureau, periodes).

  exceptionnels_pay                Suivi des paiements exceptionnels par membre
                                   et par motif.

4.3 Contenus editoriaux
------------------------
  cat_actualites     Categories actualites (reutilisees aussi pour agenda /
                     ADCI TV dans certains ecrans).

  actualites         Articles d'actualites.

  agenda             Entrees d'agenda.

  event_cat          Categories d'evenements.

  evenements         Evenements (dates, contenu, lien categorie).

  adci_tv            Contenus media / chaine ANVDKO TV ou ADCI TV.

4.4 Dons et documents
----------------------
  faire_don          Enregistrement des dons (coordonnees, montant, moyen).

  documents          Mediatheque membres (metadonnees fichier, categorie,
                     visibilite, taille, statut).

4.5 Depenses (module dedie)
----------------------------
Script SQL : anvdko/sql/create_expense_tables.sql

  depenses_anvdko       Depense (titre, categorie, description, dates, id_user).

  depense_montants      Un ou plusieurs paiements partiels par depense.

  depense_commentaires  Fil de commentaires sur une depense.

4.6 Inscriptions aux evenements (membres)
-----------------------------------------
  inscription_evenement   Inscription d'un membre a un evenement (nombre de
                          personnes, commentaire, newsletter).

4.7 Module commandes / stock (legacy ou multi-usage)
-----------------------------------------------------
Present dans anvdko/includes/php/ajax/details_commande.php et recus :

  commandes, produits_commande, produits, clients, livreurs, fermes,
  factures, journal_caisse, cat_produits, select_cats_produit, cat_nestable

Sous-systeme de gestion de commandes possiblement reutilise ou en parallele
avec la gestion associative.

4.8 Point d'attention
---------------------
Le fichier anvdko/ajax/get_expense_details.php reference une table "users"
dans un JOIN, alors que le projet utilise surtout "utilisateurs". A verifier
en base (vue, homonyme, ou correction).

5. ESPACE ADMINISTRATION (anvdko/)
--------------------------------------------------------------------------------

Authentification :
  - anvdko/index.php (formulaire)
  - anvdko/ajax.php (Ajax : session utilisateur + configuration)

Controle d'acces :
  - anvdko/includes/php/connexion_acces_page.php
    Verifie que statut utilisateur = actif.

5.1 Menu et profils (includes/php/menu.php)
---------------------------------------------
  - secretaire === "Oui"  : menu reduit (Gestion membres adherents.php,
                            Gestion dons gestions_dons.php).

  - secretaire === "Non"  : menu contenu (categories, actualites, agenda,
                            evenements, ADCI TV, configuration, utilisateurs)
                            sans le bloc comptabilite etendu de la branche suivante.

  - Sinon : menu large avec Comptabilite (paiements mensuels, recaps,
            exceptionnels), Depenses Anvdko, agenda, evenements, TV, membres,
            cartes membres, configuration, utilisateurs.

9. FLUX FONCTIONNELS (RESUME ASCII)
--------------------------------------------------------------------------------

  [Public: index, adhesion, contact]
            |
            v
       [ MySQL : anvdko_oussoukro ]
            ^
            |
  [Admin anvdko: connexion, contenus, comptabilite, depenses]
            |
            v
       [ Membres: connexion, profil, cotisations, evenements, documents ]


Etapes metier :

  1. Adhesion / membre : adhesion.php ; donnees vers membres selon branchement.
     Connexion via membres/.

  2. Administration : utilisateurs via anvdko/ ; contenus, membres, dons,
     cotisations, commandes/stock eventuel.

  3. Cotisations : paiements mensuels dans paiements ; exceptionnels via
     config_cotisations_exceptionnelles + exceptionnels_pay.

  4. Communication : actualites, agenda, evenements, TV dans les tables
     homonymes.

  5. Depenses : module Ajax + tables depenses_*.


--------------------------------------------------------------------------------
10. SECURITE ET BONNES PRATIQUES (CONSTAT CODE)
--------------------------------------------------------------------------------

  - Beaucoup de requetes par concatenation de chaines : risque injection SQL ;
    privilegier les requetes preparees (deja amorce sur upload_document.php).

  - Mots de passe en clair en base sur les logins observes : prevoir
    password_hash / password_verify.

  - Coherence bases anvdko vs anvdko_oussoukro ; table users vs utilisateurs.
